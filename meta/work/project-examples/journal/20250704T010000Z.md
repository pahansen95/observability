1. **API Evolution**: Implementation differs from stub specifications
2. **Performance**: BufferHandler can handle 500k+ events/second
3. **Composition**: FanoutHandler + filtered + sampled enables complex routing
4. **Testing**: BufferHandler is invaluable for testing observability
5. **Production**: Sampling and queuing essential for high-volume
